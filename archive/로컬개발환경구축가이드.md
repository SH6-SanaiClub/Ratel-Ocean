원래 개발 환경과 **100% 동일한 로컬 환경** 구축:

## 📋 필수 소프트웨어

### 1. MySQL 8.0 (필수)
**현재 상태**: ❌ 설치 필요  
**용도**: 로컬 데이터베이스 서버

**설치 방법**:

#### 방법 A: 공식 설치 프로그램 (권장)
1. https://dev.mysql.com/downloads/mysql/ 접속
2. **MySQL Community Server 8.0** 다운로드
3. **Windows Installer** (mysql-installer-community-8.0.x.msi) 실행
4. 설치 타입 선택:
   - **Developer Default** (권장) - 개발에 필요한 모든 것 포함
   - **Server only** - MySQL 서버만
5. Root 비밀번호: **0000** (프로젝트 설정과 일치)
6. Windows Service로 설치 (자동 시작 설정)

#### 방법 B: Chocolatey (빠른 설치)
```powershell
# 관리자 PowerShell
choco install mysql
```

#### 설치 확인
```powershell
# MySQL 서비스 확인
Get-Service -Name "*mysql*"

# MySQL 버전 확인
mysql --version
```

---

### 2. Java JDK 11 (선택사항, Maven 빌드용)
**현재 상태**: ⚠️ PATH에 없음  
**용도**: Maven으로 프로젝트 빌드 시 필요 (실행만 하면 Tomcat 내장 Java 사용)

**설치 방법**:

#### 방법 A: Eclipse Temurin (AdoptOpenJDK) - 권장
1. https://adoptium.net/ 접속
2. **Temurin 11 (LTS)** 선택
3. Windows x64 JDK 다운로드
4. 설치 시 **중요 옵션**:
   - ✅ **Set JAVA_HOME variable** 체크
   - ✅ **Add to PATH** 체크
   - ✅ **JavaSoft (Oracle) registry keys** 체크

#### 방법 B: Chocolatey
```powershell
# 관리자 PowerShell
choco install temurin11
```

#### 설치 확인
```powershell
java -version
# 출력 예: openjdk version "11.0.x"
```

---

### 3. Maven 3.x (선택사항)
**현재 상태**: ❌ 설치 안됨  
**용도**: 프로젝트 빌드 (이미 빌드된 WAR 파일이 있으면 불필요)

**설치 방법**:

#### 방법 A: 수동 설치
1. https://maven.apache.org/download.cgi 접속
2. **Binary zip archive** 다운로드 (apache-maven-3.x.x-bin.zip)
3. `C:\Program Files\` 에 압축 해제
4. 환경 변수 설정:
   - 시스템 변수 `MAVEN_HOME`: `C:\Program Files\apache-maven-3.x.x`
   - PATH에 추가: `%MAVEN_HOME%\bin`

#### 방법 B: Chocolatey
```powershell
# 관리자 PowerShell
choco install maven
```

#### 설치 확인
```powershell
mvn -version
# 출력: Apache Maven 3.x.x
```

## 🚀 빠른 설치 (자동 스크립트)

### 1단계: 환경 체크
```batch
setup-environment.bat
```

이 스크립트는:
- ✅ 설치된 소프트웨어 확인
- ✅ 덤프 파일 확인
- ✅ 필요한 설치 안내

---

### 2단계: MySQL 데이터베이스 설정

#### 옵션 A: 자동 설정 (권장)
```batch
setup-database.bat
```

**수행 작업**:
1. `sanai` 데이터베이스 생성
2. `remote_user` 계정 생성 (비밀번호: 0000)
3. 권한 부여
4. 덤프 파일 복원 (C:\program\sanaidump.sql)

#### 옵션 B: 수동 설정

**2-1. MySQL 접속**:
```bash
mysql -u root -p
# 비밀번호: 0000
```

**2-2. 데이터베이스 및 사용자 생성**:
```sql
CREATE DATABASE IF NOT EXISTS sanai 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'remote_user'@'localhost' 
  IDENTIFIED BY '0000';

GRANT ALL PRIVILEGES ON sanai.* 
  TO 'remote_user'@'localhost';

FLUSH PRIVILEGES;

EXIT;
```

**2-3. 덤프 파일 복원**:
```bash
mysql -u root -p sanai < C:\program\sanaidump.sql
# 비밀번호: 0000
```

---

### 3단계: 프로젝트 설정 변경

**db.properties를 localhost로 변경**:

```batch
update-db-config.bat
```

**변경 내용**:
```properties
# 변경 전
db.url=jdbc:mysql://192.168.0.56:3306/sanai?...

# 변경 후  
db.url=jdbc:mysql://localhost:3306/sanai?...
```

**수동 변경** (필요시):
파일: `src/main/resources/db.properties`
```properties
db.url=jdbc:mysql://localhost:3306/sanai?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8&allowPublicKeyRetrieval=true
db.username=remote_user
db.password=0000
```

## 🐛 문제 해결

### 문제 1: MySQL 설치 시 오류

**"Unable to configure service MySQL80"**

**해결책**:
1. 이전 MySQL 제거:
   ```powershell
   sc delete MySQL80
   ```
2. 재설치 또는:
   ```powershell
   # 서비스 수동 생성
   "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe" --install MySQL80
   ```

---

### 문제 2: MySQL 접속 거부

**"Access denied for user 'root'@'localhost'"**

**해결책**:
1. MySQL을 안전 모드로 시작:
   ```powershell
   # 서비스 중지
   net stop MySQL80
   
   # 안전 모드로 시작
   mysqld --skip-grant-tables
   ```

2. 새 터미널에서:
   ```bash
   mysql -u root
   ALTER USER 'root'@'localhost' IDENTIFIED BY '0000';
   FLUSH PRIVILEGES;
   EXIT;
   ```

3. 정상 모드로 재시작

---

### 문제 3: 덤프 복원 실패

**"Unknown database 'sanai'"**

**해결책**:
데이터베이스를 먼저 생성:
```sql
CREATE DATABASE sanai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

**"Error 1064: Syntax error"**

**해결책**:
덤프 파일 인코딩 확인:
```powershell
# UTF-8로 변환
Get-Content C:\program\sanaidump.sql | Set-Content -Encoding UTF8 C:\program\sanaidump_utf8.sql
```

---

### 문제 4: 프로젝트 실행 시 DB 연결 오류

**체크리스트**:
1. MySQL 서비스 실행 중?
   ```powershell
   Get-Service MySQL80
   ```

2. db.properties가 localhost로 변경됨?
   ```batch
   type src\main\resources\db.properties | findstr "localhost"
   ```

3. 사용자 및 권한 확인:
   ```sql
   SELECT User, Host FROM mysql.user WHERE User='remote_user';
   SHOW GRANTS FOR 'remote_user'@'localhost';
   ```

4. 방화벽 확인:
   ```powershell
   Test-NetConnection -ComputerName localhost -Port 3306
   ```

---

### 문제 5: Character Encoding 문제

한글이 깨지는 경우:

**해결책**:
```sql
-- 데이터베이스 설정 확인
SHOW VARIABLES LIKE 'character%';

-- 테이블 변환 (필요시)
ALTER DATABASE sanai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
ALTER TABLE 테이블명 CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 📊 환경 설정 비교

### 원격 환경 (이전)
```
DB Host: 192.168.0.56:3306
DB Name: sanai
DB User: remote_user
DB Pass: 0000
```

### 로컬 환경 (현재)
```
DB Host: localhost:3306 (127.0.0.1)
DB Name: sanai (덤프에서 복원)
DB User: remote_user (동일)
DB Pass: 0000 (동일)
```

### 변경 사항
- ✅ **Host만 변경**: 192.168.0.56 → localhost
- ✅ **데이터베이스 이름**: 동일 (sanai)
- ✅ **사용자**: 동일 (remote_user)
- ✅ **비밀번호**: 동일 (0000)
- ✅ **스키마**: 덤프 파일로 완전 복원
- ✅ **기술 스택**: 100% 동일
